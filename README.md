# ilo-sitelen

A toki pona writing mode for Fcitx5.

Based on jan Komi's [ibus input table](https://github.com/neroist/sitelen-pona-ucsur-guide/blob/main/ibus-tables/sitelen-pona.ibus-table).

## Installation

First, install `fcitx5-chinese-addons` (might be named `fcitx5-table` on your distribution),
as it adds the required `table` input method.

Download the repository, and run `./install.sh`.
